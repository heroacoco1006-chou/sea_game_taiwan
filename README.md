# 大航海福爾摩沙（Age of Sail: Formosa）

給國小五、六年級學生的 2D 航海歷史角色扮演與貿易遊戲，透過遊玩理解**台灣在大航海時代（1600～1662）的東亞貿易角色**。

- 🌐 **線上直接玩（免安裝）**：<https://heroacoco1006-chou.github.io/sea_game_taiwan/>
- 🧭 玩法風格致敬經典航海貿易 RPG（原創製作，不使用任何商業遊戲版權素材）
- 🧑‍✈️ 三位主人翁：漢人海商（林海生）、荷蘭 VOC 商務員（彼得・范德堡）、日本朱印船商人之女（田中千代），各 10 章主線劇情
- 🗺️ 以台灣為中心的東亞與東南亞 22 座港口、12 處圖文探險地點與 126 筆歷史文化圖鑑
- ⚓ 完整系統：自由貿易（流行／供需）、HD-2D 港町街道（支援舊版回退）、8 種歷史船型建造與改裝、5 艘艦隊編隊、11×7 六角格回合制海戰、25 位夥伴招募與專屬任務、新手領航教學

## 技術架構

- **引擎與語言**：Phaser 3 + TypeScript + Vite（港町街景以 Three.js 共用 WebGL 畫布呈現 HD-2D 視角，支援 `?townRenderer=legacy` 回退）
- **平台**：網頁版（GitHub Pages 自動部署，支援桌機鍵盤滑鼠、平板與手機觸控，並支援存檔 `.json` 備份與還原）
- **素材授權**：自製生成素材與 CC BY 4.0 音樂，詳見 [assets/CREDITS.md](./assets/CREDITS.md)

## 本機執行（開發版）

```bash
npm install
npm run dev
```

瀏覽器開啟 `http://localhost:5173` 即可遊玩。

### 操作方式

- **電腦**：方向鍵或 WASD 航行／走動，靠近港口或建築按 `Enter` 互動，或直接滑鼠點擊港町建築與介面
- **平板／手機**：支援畫面虛擬方向鍵與動作鍵，亦可在「設定」中調整觸控按鍵開關
- **存檔與備份**：進港與旅館休息會自動存檔，也可在「存檔到…」頁面將存檔下載成 `.json` 備份檔，方便跨裝置繼續遊玩
